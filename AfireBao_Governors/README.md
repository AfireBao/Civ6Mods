# AfireBao 的总督修改

这是一个要求同时拥有《迭起兴衰》和《风云变幻》的独立总督平衡模组。技能树以 Better Balanced Game 7.4.6 为基础，并将本模组涉及的总督就职时间调整为：

- 阿玛妮、莫克夏、马格努斯、梁、平伽拉、瑞纳、维克多、易卜拉欣：3 回合。
- 秘密结社总督未被本模组修改。

本模组已经包含运行这些技能所需的最小依赖，不需要启用 BBG。`modinfo` 会阻止本模组与 BBG 同时启用，以避免重复写入总督数据。

## 安装

将整个 `AfireBao_Governors` 文件夹复制或链接到：

`%USERPROFILE%\Documents\My Games\Sid Meier's Civilization VI\Mods\AfireBao_Governors\`

## 文件说明

- `Data/Governors.sql`：BBG 的《迭起兴衰》总督基础修改。
- `Data/Governors_XP2.sql`：BBG 的《风云变幻》追加修改。
- `Data/Ibrahim.sql`：从 BBG 奥斯曼文件中提取的易卜拉欣部分。
- `Data/Dependencies.sql`：独立运行所需的最小依赖。
- `Data/ZZ_Establishment.sql`：AfireBao 就职时间最终覆盖；文件名前缀确保其在 BBG 基础脚本之后加载。
- `Text/`：BBG 中英文总督文案及本模组的就职时间同步。

`ZZ_Establishment.sql` 的 `ZZ_` 前缀是有意保留的。文明 6 会按同一 `UpdateDatabase` 动作内的文件路径排序执行脚本；若将其改回 `Establishment.sql`，它会先于 `Governors.sql` 执行，随后 BBG 基础数据会把部分总督覆盖回 4 回合。

修改 SQL 或替换模组版本后，应完全退出并重新启动游戏再创建或读取存档；仅返回主菜单不会重建当前进程中的 Gameplay 数据库。

## 验证

开发时已在一份未加载 BBG 的《风云变幻》Gameplay 数据库副本中按文明 6 的实际路径排序执行全部 SQL；脚本均成功执行，最终外键检查无残留，八位总督的 `TransitionStrength` 均为 150（3 回合）。其中维克多“驻军司令”为 +5 战斗力；莫克夏“守护圣人”同时保留 BBG 的信仰转科技/文化效果和原版额外升级效果。
